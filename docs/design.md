# 设计说明：从四个原型到一个工作流

ScriptCut 整合了四套独立做出来的自动剪辑原型。它们各自解决了流程中的一段，也重复造了很多轮子：
四套都有自己的配音对齐、自己的音效合成、自己的渲染脚本，各自的分镜格式互不相通。这次整合的目标是
**一个数据契约 + 两个渲染后端 + 三种 Agent 接口**，并把每个原型里踩过的坑固化成代码和校验规则。

## 四个原型分别贡献了什么

| 原型 | 做法 | 留下来的东西 |
|---|---|---|
| 新闻解说剪映工作流（小 Lin 说式） | 文案 → 分镜 xlsx → 静音对齐 → 剪辑计划 → 剪映草稿（组合预设注入） | **离线静音对齐算法**（停顿 DP 吸附标点 + 音节插值，`align/silence.py` 原样保留并带测试）；数字中文读法音节数；字幕断行规则；「只覆盖本工具生成且未被剪映打开过的草稿」；素材类型划分；事实核查表 |
| 知识科普剪映工作流 | storyboard.yaml + 素材库 → LibTV 出图 → fish 识别对齐 → 剪映草稿（MG 关键帧） | **分镜格式**（镜头 / 元素 / trigger / red / cap / over）；**MG 入场预设**（逐帧采样、过冲、挤压，`motion.py`）；版式模板与「等效边长」尺寸；遮挡 / 拥挤 / 开头空画面检查；顶部逐字标题；出图提示词拼接与抠白底；识别对齐 |
| 代码做视频（Canvas / Remotion 广告与科普） | 逐句 TTS → 旁白驱动 timeline.json → Canvas 纯函数逐帧 → Playwright 并行渲染 → numpy 音效配乐 → 两遍 loudnorm | **Canvas 渲染引擎**（`seek(t)` 纯函数、分段并行、运动模糊子采样）；**旁白是主时钟**；关键词时刻 `kw()`；音效峰值对齐；砸前静止；静帧总览自检；cues 采集；TTS 读法与 ASR 回听校对；配乐闪避；确定性检查 |
| 吐槽合集（小红书竖屏） | 口播稿 → 导演方案 → 代码动画 → 分层交付 → 剪映草稿 | **分层交付**（无字幕画面 + 可编辑字幕 + 分轨音频 = 剪映 flat 模式）；导演方案三选一的思路；平台遮挡区；字体授权记录 |

## 为什么是两个渲染后端

- **Canvas（代码出片）**：上限高、完全可复现、无需任何桌面软件，Agent 能自己看静帧迭代；适合广告、数据可视化、批量生产。
- **剪映草稿**：国内创作者的最后一公里在剪映里——换字体、调节奏、加花字。草稿后端把同一份 timeline 装成可编辑的分轨草稿。
- 两个后端读同一个 `timeline.json`：位置、入场采样帧、标题逐字时刻、音效提示点都在这里算好，后端只做「画」。

## 关键取舍

1. **分镜用 YAML，不用 xlsx**：Agent 读写 YAML 最稳；xlsx 降级为只读审阅表（`scriptcut sheet`）。
2. **对齐三选一，输出同一结构**：TTS 逐句（最准，时长已知）/ fish 识别（录音最准）/ 离线静音（零成本，多组阈值自动择优）。
3. **TTS 逐句合成再拼接**：句间停顿由风格控制（同段 / 换段 / 章节前后），句内用静音对齐分到字；换音色或改一句只重合成那一句（manifest 记录读法）。
4. **文字默认本地渲染**（`kind: word`）：清晰、零成本、不会写错；需要手写风时才让 AI 画（≤12 字）。
5. **出图可插拔**：火山方舟 · 豆包 Seedream / 阿里百炼 · 通义万相 / 硅基流动 / OpenAI 兼容接口 / 任意命令行 / 人工，全部由用户接入自己的 Key。原型里绑定的 LibTV 改成 `SCRIPTCUT_IMAGE_CMD` 模板即可接回。
6. **剪映组合预设注入没有并入**：它依赖本机预设目录和剪映资源缓存，换一台电脑就不可用；公开版改为**全原生可编辑草稿**：图片元素 = 原始素材 + 关键帧（入场动画逐帧采样后精简成少量关键帧），文字 / 标题 / 字幕 = 剪映原生文本（关键词用文本分段颜色，标题用「逐字显影」动画），音效逐条分轨；任何人都能打开、直接改、替换素材。
7. **草稿可自检**：`jianying/preview.py` 按剪映的规则（等比适应 × 缩放、半画布坐标、关键帧线性插值、字号 × 画布短边 × 0.006）把草稿合成成预览图，Agent 不开剪映也能检查位置和时序；示例项目里与 Canvas 渲染逐镜对比一致。
8. **出图不内置服务**：到出图这一步如果没接入用户自己的 API，流程停下并返回 `need_image_api` 和填写说明，不会静默用占位图交付。
9. **自定义画面而不是一套万能模板**：广告片的好画面都是专门写的。ScriptCut 只规定契约（`draw / overlay / cues`）和工具（`api.js`），引擎负责其余一切。

## 原型里的坑（已固化为代码 / 校验）

- 换镜点只由配音决定；元素入场太晚就提前，不推迟换镜（否则总时长被拉长）。
- 第一个元素的 trigger 要在镜头开头，否则换镜后空画面 → timeline 警告。
- YAML 1.1 把键 `on` 解析成 `True` → 叠加字段叫 `over`，写 `on:` 直接报错。
- 渲染缓存不能用 Python `hash()` 做种子（每次进程不同）→ 全部用 crc32 / md5。
- mp3 带封面图时剪映当视频解析 → 配音统一 wav。
- 剪映打开过的草稿被加密、生成 `Timelines/` → 拒绝覆盖。
- 每帧先铺底色：半透明边缘不清空会让故障帧残留到后续帧。
- 视频素材在无头 Chromium 里不一定能解码、也不保证逐帧确定 → 预先抽成图片序列。
- 运动模糊少于 8~12 个子采样时，快速光点会裂成分离的珠子。
- 冲击音效要让实测峰值落在事件上，而不是文件开头（约差 1 帧）。
- 画面里的数字读法：「2026年」逐位、「2个」读两、千分位去掉、百分号读「百分之」。
- requests 不读 Windows 系统代理 → `FISH_PROXY` 显式配置。

## 公开版去掉了什么

- 所有 API Key、音色 ID、本机路径、代理地址（原型的 `.env` 不进入本仓库）。
- 品牌客户内容（广告脚本、Logo、色卡、合规文案）与有版权风险的截图、人物照片、人物参考图。
- 绑定本机的剪映组合预设、私有字体资源 ID。
